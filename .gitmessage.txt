# 📝 Git Commit Message Template
# -----------------------------------------------
# ✅ Type에는 아래 중 하나를 입력하세요.
# - Feat: 새로운 기능 추가
# - Fix: 버그 수정
# - Design: UI/UX 디자인 변경
# - !BREAKING CHANGE: API 변경 (큰 변경 사항)
# - !HOTFIX: 긴급 버그 수정
# - Style: 코드 스타일 변경 (포맷팅, 세미콜론 추가 등, 코드 변경 없음)
# - Refactor: 코드 리팩토링 (기능 변경 없음)
# - Comment: 주석 추가/변경
# - Docs: 문서 수정 (README 등)
# - Test: 테스트 코드 추가/수정 (프로덕션 코드 변경 없음)
# - Chore: 빌드 설정, 패키지 관리 등 수정 (프로덕션 코드 변경 없음)
# - Rename: 파일/폴더명 변경 (코드 변경 없음)
# - Remove: 파일 삭제 (코드 변경 없음)
# - SH: 커스텀shell 추가
# - docker: dockerfile, docker comopose 파일
# - git: git convention 설정 변경 시
# -----------------------------------------------
# Type: 내용
# ex. Feat: 회원 가입 API
